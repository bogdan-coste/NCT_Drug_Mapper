|   |   +-- lexical/                               |  rerank/            - Cross-encoder rerank of top candidates.
|   |   |   +-- bm25_index.py                      |  query/             - Query rewrite, routing, multi-query, HyDE.
|   |   +-- retrieval/                             |  cache/             - Exact + semantic cache to cut latency & LLM cost.
|   |   |   +-- retriever.py                       |  prompts/           - Versioned prompt templates.
|   |   +-- rerank/                                |  llm/               - LLM client with retries, timeouts, model fallback.
|   |   |   +-- reranker.py                        |  generation/        - Grounded answers with citations & 'I don't know'.
|   |   +-- query/                                 |  eval/              - Golden set + faithfulness / recall@k / RAGAS metrics.
|   |   |   +-- rewriter.py                        |  observability/     - Traces, per-stage latency, cost, quality dashboards.
|   |   +-- cache/                                 |  security/          - Auth, chunk-level ACL, PII redaction.
|   |   |   +-- semantic_cache.py                  |  api/               - FastAPI serving path only (not the indexer).
|   |   +-- prompts/                               |  pipelines/         - Separate offline index pipeline and online
|   |   |   +-- prompt_templates.py                |                       query pipeline.
|   |   +-- llm/                                   |  utils/             - Shared helpers.
|   |   |   +-- llm_client.py                      |  jobs/              - Scheduled index, reindex, and nightly eval jobs.
|   |   +-- generation/                            |  -----------------------------------------------------------------
